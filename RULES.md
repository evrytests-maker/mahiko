# Mahiko rules

Read `AGENTS.md` and `prefill.md` before changing the project. `frontend/` and `skills/` are separate handoffs: do not merge, edit or replace them unless the user explicitly asks. Keep OMP external and use the exact version in `omp.lock.json`.

Before a merge task, begin with `prompts/00-start-merge.md`. Keep runtime discovery prompt-free; real OMP requests are permitted only for the bounded integration verification described there.
